# 隐藏玩偶狙击手 · 双章体验版

试玩：https://jianyucong0702-cmd.github.io/hidden-hippo/

第一章玩具百货店：10 只，5 分钟。第二章城市夜市：12 只，6 分钟。两章都有 A/B 两套布局、限时与休闲模式，各章各模式独立保存成绩。菜单“探索章节”可选择章节；首关通关后也可前往夜市。后两章仍在制作。

初次打开会显示素材准备状态，就绪后可开始；加载失败可点击重试。资源全部同源托管，不需要 ChatGPT 登录。中国境内访问已获用户手机实测反馈，不能保证所有地区或运营商。

无依赖安装。将 dist 作为静态根目录发布。测试：在项目目录运行 node tests/flow.mjs。GitHub Pages 使用 gh-pages 分支根目录。浏览器存档留在当前设备，换设备不自动同步。

素材为现有绘本背景与透明河马，尚未制作精细遮挡或完整角色动画；这是可试玩版本。
