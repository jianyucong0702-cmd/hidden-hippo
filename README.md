# 隐藏玩偶狙击手 · 首关体验版

本次交付是第一关可玩版本，完整 V1.0 尚未验收。其余三关仅展示已确认场景参考，不可游玩。

## 运行
需要 Python 3，终端在项目目录运行：

    python3 -m http.server 8080 --directory dist

浏览器打开 http://localhost:8080 。不能直接以 file:// 打开，因为使用浏览器原生 ES Modules。无依赖安装，无外部网络资源。部署时将 dist 作为静态网站根目录。

## 操作
观察：鼠标拖动、滚轮缩放；手机单指拖动、双指缩放。
瞄准：进入瞄准后移动准星，点击独立射击按钮或按空格射击。手机准星在手指上方约 52 CSS 像素。瞄准时双指移动/缩放场景；桌面可以 Shift 拖动。
暂停：右上角按钮。切换标签页自动暂停。
重玩：自动切换 A/B 固定预设，各 10 只。

## 规则
每命中目标 +100，前 3 次误射免扣分，之后每次 -10，线索每次 -30，最低 0 分。线索扣分以总扣分累计，在当前积分为零时仍会计入最终成绩。
限时通关：剩余整秒 ×2 奖励。休闲模式没有时间奖励。无连续命中奖励，避免重复刷分。
第一关三星：准确率至少 90%、不用提示、限时 180 秒内 / 休闲 360 秒内；二星：准确率至少 65%、提示不超过 2 次；其余完成得一星。未完成零星。
两种模式分别保存最高分、最快时间、最高准确率和最高星级；各项纪录可能来自不同场次。保存在当前浏览器 localStorage，换设备不自动同步。未完成局不保存。

## 文件结构
- dist/index.html、style.css：界面与响应式布局
- dist/game.js：Canvas 渲染、交互、音频、状态、存档
- dist/engine.js：目标配置、坐标转换、评分
- dist/assets/：四张参考场景、透明玩偶和主角三姿态图
- tests/flow.mjs：状态流与规则回归检查
- TEST_REPORT.md：真实测试范围和未完成项

## 测试
需要 Node.js 22 或更高：

    node tests/flow.mjs

## 素材
四张场景取自用户此前确认的 V2 图，原尺寸 1672×941，RGB 单层，没有假装成原生 4K。透明河马依据用户选定灰紫河马参考制作，1254×1254 RGBA。主角为本次生成的原创成年男性三姿态图，1774×887 RGBA。原图并非骨骼或逐帧动画。
背景音乐及音效使用 Web Audio 自行合成，无外部录音或音乐采样；玩具店一套原创循环。音乐与音效可独立关闭。
